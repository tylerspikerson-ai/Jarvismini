# J.A.R.V.I.S. - Настоящая Легковесная LLM

## 🚀 Что это?

Это **полноценная нейросеть** (не заглушка!), работающая локально на вашем ПК.

### Модель: Qwen2.5-0.5B-Instruct
- **0.5 миллиарда параметров** - ультра-легкая
- **~1 GB памяти** при загрузке
- **Работает на CPU** - не требует видеокарты
- **Поддерживает русский язык**

## 📦 Установка

```bash
pip install torch transformers huggingface_hub
```

## 🎯 Запуск

```bash
python jarvis_llm.py
```

**Первый запуск:** 2-5 минут (скачивание модели ~1GB)
**Последующие:** 10-30 секунд (модель кэшируется)

## 💬 Пример диалога

```
Вы: Привет! Расскажи о себе
Джарвис: Привет! Я Джарвис, ваш AI-помощник на базе нейросети Qwen...

Вы: Какая погода сегодня?
Джарвис: Я не имею доступа к данным о погоде в реальном времени...

Вы: Напиши код сортировки пузырьком на Python
Джарвис: def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr
```
