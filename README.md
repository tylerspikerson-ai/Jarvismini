# J.A.R.V.I.S. - Ультра-легкая LLM система

## 📋 Описание

**J.A.R.V.I.S.** (Just A Rather Very Intelligent System) - это ультра-легкая, быстрая и эффективная система с собственным интерфейсом, работающая на минимальных требованиях к железу.

### ✨ Особенности

- **Минимальные требования**: Только Python 3.7+, никаких дополнительных зависимостей
- **Работает без интернета**: Полностью автономная система
- **Два режима работы**: 
  - Консольный интерфейс (всегда доступен)
  - GUI интерфейс (при наличии Tkinter)
- **Экспорт в ЗИП**: Создание самодостаточных архивов для переноса
- **Сохранение истории**: Автосохранение диалогов
- **Русский язык**: Полная поддержка русского языка из коробки

## 🚀 Быстрый старт

### Запуск

```bash
# Консольный режим (работает везде)
python3 jarvis_console.py

# GUI режим (требуется Tkinter)
python3 jarvis.py
```

### Команды

| Команда | Описание |
|---------|----------|
| `/help` | Показать справку по командам |
| `/clear` | Очистить историю переписки |
| `/save` | Сохранить текущий диалог в файл |
| `/zip` | Создать ЗИП архив системы |
| `/quit` или `/exit` | Выйти из программы |

## 📦 Создание ЗИП архива

Для создания переносимого архива:

1. Запустите программу
2. Введите команду `/zip`
3. Архив будет создан в текущей директории

Архив содержит:
- Основной скрипт `jarvis.py`
- Конфигурационный файл
- Историю диалогов
- README с инструкцией

## 💾 Форматы сохранения

Диалоги сохраняются в формате JSON:

```json
[
  {
    "role": "user",
    "content": "Привет!"
  },
  {
    "role": "assistant", 
    "content": "Здравствуйте!"
  }
]
```

## ⚙️ Конфигурация

Файл `jarvis_config.json` позволяет настроить:

```json
{
  "model_path": "",
  "model_type": "lightweight",
  "max_context_length": 2048,
  "temperature": 0.7,
  "theme": "dark",
  "language": "ru",
  "auto_save": true,
  "zip_on_exit": false
}
```

## 🔧 Требования

- **Python**: 3.7 или выше
- **Память**: < 50 MB
- **Место на диске**: < 1 MB
- **Зависимости**: Только стандартная библиотека Python

## 📁 Структура проекта

```
/workspace/
├── jarvis.py           # GUI версия (Tkinter)
├── jarvis_console.py   # Консольная версия
├── jarvis_config.json  # Конфигурация
├── README.md           # Документация
└── *.zip              # ЗИП архивы
```

## 🎯 Возможности расширения

Система разработана с возможностью подключения внешних моделей:

1. **llama-cpp-python** - для работы с GGUF моделями
2. **transformers** - для моделей HuggingFace
3. **Собственные паттерны** - расширение базы ответов
