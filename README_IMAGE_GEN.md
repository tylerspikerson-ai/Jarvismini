# 🎨 J.A.R.V.I.S. Image Generator

## Ультра-легкий генератор изображений на базе Stable Diffusion

Система генерации изображений с минимальными требованиями к железу, способная работать на CPU и слабом оборудовании.

---

## 🚀 Быстрый старт

### 1. Установка зависимостей

**Минимальный режим (демо-режим, заглушки):**
```bash
pip install Pillow
```

**Полноценный режим (AI генерация на Stable Diffusion):**
```bash
# Для CPU
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install diffusers transformers accelerate safetensors Pillow

# Для GPU (NVIDIA CUDA)
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
pip install diffusers transformers accelerate safetensors Pillow
```

### 2. Запуск

**Консольная версия:**
```bash
python jarvis_image.py --console
```

**GUI версия (графический интерфейс):**
```bash
python jarvis_image.py --gui
```

**Быстрая генерация одной командой:**
```bash
python jarvis_image.py --prompt "красивый пейзаж с горами и озером"
```

**Создание ЗИП архива для переноса:**
```bash
python jarvis_image.py --zip
```

## ⚙️ Требования к системе

| Режим | ОЗУ | Место на диске | Время генерации (512x512) |
|-------|-----|----------------|---------------------------|
| **Демо** | <100 MB | <1 MB | <1 сек |
| **CPU** | 2-4 GB | ~4 GB (модель) | 30-120 сек |
| **GPU** | 4-8 GB | ~4 GB (модель) | 5-20 сек |

### Минимальные требования:
- Python 3.8+
- 2 GB ОЗУ (для демо-режима)
- 4 GB ОЗУ (для AI генерации)
- CPU или GPU (опционально)

### Рекомендуемые требования:
- Python 3.10+
- 8+ GB ОЗУ
- GPU с 4+ GB VRAM (NVIDIA)
- SSD для быстрой загрузки модели

## 🎯 Возможности

### ✅ Основные функции:
- **Генерация по текстовому описанию** - создаёт изображения по промпту

## 💡 Советы по оптимизации

### Для слабого железа:
1. Используйте меньшее разрешение (256x256 или 512x512)
2. Уменьшите количество шагов инференса (15-20 вместо 50)
3. Используйте модель типа `tiny` или `cpu`
4. Закройте другие приложения для освобождения ОЗУ

### Для ускорения генерации:
1. Используйте GPU вместо CPU (в 5-10 раз быстрее)
2. Включите xformers для оптимизации памяти
3. Используйте DPM Solver scheduler (уже включен по умолчанию)
4. Кэшируйте модель между запусками

### Для качества изображений:
1. Увеличьте количество шагов (30-50)
2. Используйте детальные промпты на английском
3. Настройте guidance scale (7-12)
4. Добавьте negative prompt для исключения артефактов

## 🐛 Решение проблем

### Ошибка: "No module named 'torch'"
```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
```

### Ошибка: "No module named 'diffusers'"
```bash
pip install diffusers transformers accelerate safetensors
```

### Ошибка: "CUDA out of memory"
- Уменьшите разрешение изображения
- Уменьшите batch size до 1
- Используйте модель типа `cpu` или `tiny`
- Закройте другие приложения использующие GPU

### Ошибка: "Tkinter not available"
- Установите tkinter: `sudo apt-get install python3-tk` (Linux)
- Или используйте консольную версию: `python jarvis_image.py --console`

### Медленная генерация на CPU
- Это нормально, CPU в 5-10 раз медленнее GPU
- Уменьшите разрешение и количество шагов
- Используйте модель `tiny`

## 📝 Формат промптов

### Хороший промпт:
```
красивый пейзаж с горами и озером на закате, фотореализм, высокое разрешение, детализированный
```

### Плохой промпт:
```
картинка горы
```

### Negative prompt (что исключить):
```
ugly, blurry, low quality, distorted, deformed, watermark, text, signature
```

### Стилевые ключевые слова:
- `фотореализм, photograph` - реалистичное фото
- `digital art, digital painting` - цифровая живопись
- `oil painting` - масляная живопись
- `anime, manga` - аниме стиль
- `cyberpunk, sci-fi` - научная фантастика
- `fantasy, medieval` - фэнтези
- `minimalist, abstract` - абстракция
